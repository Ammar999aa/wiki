# Model page — handoff to the wiki team

`model-page.html` is the finished Model page: one self-contained file, 152 KB.
Open it in a browser to see exactly what it should look like.

## What it is

A dry-lab page covering the screening pipeline, its self-audit, a validation
against public data, and the wet-lab design. 12 sections, 7 figures, 10 tables,
31 references, plus an interactive candidate explorer.

## Before you port it — read this

**This is not a drop-in file for the iGEM wiki.** It is a reference
implementation. The iGEM wiki has its own template, navigation, and CSS, and
pasting this file in whole will collide with them. Specifically:

| Thing in this file | What to do on the wiki |
|---|---|
| Left sidebar nav (`<nav class="rail">`) | **Delete it.** The wiki supplies its own navigation. Keep the section IDs (`#s1`…`#s12`) so in-page links still work. |
| `<style>` block, ~700 lines | Namespace every selector, or scope it under one wrapper class. Bare `table`, `p`, `h2`, `section` selectors **will** leak into the wiki's own styling. |
| `<title>` | Drop it; the wiki sets the page title. |
| Google Fonts `<link>` | Check whether the wiki allows external stylesheets. If not, fall back to system fonts — the layout survives it. |
| `<script>` block at the end | Keep it. It renders the data tables, the charts and the explorer. Without it several sections come out empty. |
| `prefers-color-scheme` dark blocks | Keep or drop depending on whether the wiki has a dark mode. Harmless either way. |

**The single biggest risk is the CSS.** Do a scoping pass before you paste, not
after.

## Content that must not be silently changed

Some of this page's wording is load-bearing. If you shorten it, you break a
factual claim:

1. **Retracted claims stay visible.** Two former headline results (an *ibpAB*
   conservation superlative, a DUF3494 ice-binding protein) are shown as
   withdrawn, with the reason. Do not tidy them away — that they are shown is
   the point.
2. **Data availability is deliberately conservative.** The survey's data
   repository is a public staging snapshot, not a citable release. Do **not**
   add a DOI, an ENA accession, or a licence claim for the raw reads: the
   survey's own README forbids it until their release gates pass.
3. **Sample provenance.** Section 11 states the 1,221 metagenomes were not
   generated by this iGEM team. Keep that.
4. **Every number is sourced.** All figures trace to released tables or audit
   reports. Do not round, retype, or "clean up" numbers — ask instead.
